# 已知限制与排查

- 本项目非官方；协议对齐固定桌面提交，没有承诺兼容所有未来 Magpie 版本。
- 手机显示已共享且已导入的内容，既不实时读取桌面数据库，也不直接读取供应商账单。
- 参考费用采用公开价格及有限规则，不能复现所有桌面自定义费率、订阅优惠与模型映射。见[差异说明](DATA_AND_CALCULATIONS.md)。
- 额度是历史百分比。过期判定和跨账号简单平均只是展示策略，不能替代实时绝对余额。
- 后台任务受 Android 和厂商省电策略影响；首次导入、PBKDF2 派生及大量历史重算可能耗时。
- 全量查询和 JSON 解析仍有内存开销；非常大的归档需要进一步性能验证。
- 第三方 WebDAV 的权限、路径、元数据和 XML 行为存在差异；不能保证所有实现都兼容。
- 切换连接保留各自历史库；清除当前历史不等于清除所有旧连接数据。
- 没有受维护的正式签名升级渠道时，CI/debug APK 的签名可能不同，请先阅读构建说明。
- Android 16 x86_64 隔离模拟器验证时曾发生 ART/libart 原生 SIGSEGV，包括密钥派生及 EmojiCompat 线程；原因未确认，不能据此断定是真机故障，也不能声称真机稳定性已完全验证。另一个可复现的 Kotlin 启动初始化竞态已修复。

## 常见问题

**连上了但没有数据**：检查桌面是否开启共享用量、目录是否一致、云端是否确实有 .magpie-usage 文件；配置备份与共享用量是两件事。

**口令错误或文件损坏**：WebDAV 应用密码和 Magpie 同步口令不可混用；也可能是文件写入未完成或认证数据损坏。

**手机比桌面少**：检查最近上传时间、云端保留范围、筛选和时区；手机不能恢复第一次导入前已被云端删除的历史。

**费用不同**：先比请求及 Token，再比价格表更新日期、自定义费率和实际账单规则。

**无法覆盖安装**：核对 applicationId、versionCode 和签名。卸载重装会影响本机数据，不要把它当作无损升级。
