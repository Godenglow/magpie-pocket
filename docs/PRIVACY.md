# 隐私与凭据

## 网络访问

应用访问你配置的 WebDAV，以及在你主动更新价格表时访问 models.dev。前台检查与可选的 WorkManager 后台任务也会访问 WebDAV。代码没有接入本项目运营的统计服务器、广告 SDK 或分析 SDK。

远端接口仅有目录查询和文件下载，不提供上传、远端删除或恢复配置备份功能。HTTPS 使用系统证书验证；正式服务禁止明文 HTTP，本地开发回环地址例外。

## 本地数据

- WebDAV 应用密码和 Magpie 同步口令经 Android Keystore 中的 AES 密钥加密，密文保存在应用私有 SharedPreferences。
- 账号、服务器地址、目录等配置保存在私有 DataStore，不能将它们误认为都在 Keystore 中。
- 解密后的用量及额度历史保存在应用私有 Room 数据库中；数据库本身没有额外的 SQLCipher 加密层。
- 服务器、账号、目录组成连接标识，用来隔离本机归档。连接标识的哈希不是对请求记录的加密。
- 配置与凭据保留在应用进程内存中以执行一次同步。设备 root、调试环境或系统被攻破不在 Keystore 能保证隔离的范围内。
- AndroidManifest 设置 allowBackup=false，避免普通应用备份携带这些数据。

应用不主动获取提示词和完整聊天正文；但下载文件和保留的原始记录由桌面端决定，不能承诺其所有字段永远只包含数字。发布问题报告前应自行脱敏。

## 清理与控制

可以关闭后台任务、清理当前连接的本机归档或卸载应用。清理本机历史不删除 WebDAV 云端文件；重新同步会重新导入云端仍有的记录。

本机采用按连接分库，切换连接并不等于销毁旧连接归档。需要移除应用全部本地数据时，可在 Android 应用设置中清除存储或卸载；不要以切换账号代替清除数据。

截图、日志、诊断文本可能出现账号、设备名、模型与用量。请勿在 GitHub Issue 中上传真实应用密码、同步口令、原始共享文件或未脱敏的数据库。
